# BLA-06 Management and Cost

## Key Concepts:
•	CloudWatch = Monitoring and performance.
•	CloudTrail = Tracking user activity and API calls.
•	Cost Explorer = Analyzing costs.
•	AWS Budgets = Managing spending targets.
•	Pricing Calculator = Estimating costs.
•	Spot Instances = Discounted spare EC2 capacity.
•	AWS Support = Technical assistance.
•	Trusted Advisor = Recommendations and best practices.
