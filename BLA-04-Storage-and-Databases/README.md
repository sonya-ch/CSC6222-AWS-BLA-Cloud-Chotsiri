# BLA AWS Cloud ☁️
# Storage and Databases

## Introduction

Welcome to **BLA AWS Cloud**, a structured learning project designed to help learners understand AWS Cloud fundamentals and prepare for the **AWS Certified Cloud Practitioner (CLF-C02)** certification exam.

This project focuses on explaining AWS concepts in simple, practical English, using real-world scenarios, service comparisons, video lessons, and exam-style practice questions.

The goal is not just to memorize AWS service names, but to understand **what each service does, when to use it, and how to identify the correct service based on a business or technical requirement.**

## 🎯 Learning Objectives

By completing this learning project, learners will be able to:

* Understand the fundamentals of AWS Cloud computing.
* Identify common AWS services and their primary use cases.
* Understand the differences between AWS storage, database, compute, and networking services.
* Recognize important AWS terminology and exam keywords.
* Apply AWS concepts to real-world scenarios.
* Review key concepts using concise exam notes and practice questions.
* Build confidence in preparing for the AWS Certified Cloud Practitioner exam.

## ☁️ Topics Covered

### 1. AWS Storage & Databases

This module introduces five important AWS services:

| Service         | Main Concept                  | Common Use Cases                                              |
| --------------- | ----------------------------- | ------------------------------------------------------------- |
| Amazon S3       | Object storage                | Images, videos, backups, and data files                       |
| Amazon EFS      | Shared file storage           | Shared file systems for multiple compute resources            |
| Amazon RDS      | Managed relational databases  | SQL-based applications and structured relational data         |
| Amazon Aurora   | AWS-built relational database | MySQL-compatible and PostgreSQL-compatible database workloads |
| Amazon DynamoDB | NoSQL database                | Highly scalable, low-latency applications                     |

## 🎓 Certification Goal

The primary certification goal is the **AWS Certified Cloud Practitioner (CLF-C02)** exam.

The lessons are intended as a learning and revision resource. They should be used alongside the current official AWS exam guide and AWS documentation.

Practice questions in this repository are original study questions and are not official AWS exam questions.

## 🚀 Getting Started

1. Start with Video 1 to understand the theory.
2. Continue with Video 2 to learn how to select the right service.
3. Watch Video 3 and review `NOTE.md`.
4. Answer the practice questions without looking at the answers first.
5. Revisit any concepts that you find difficult.
6. Review the official AWS exam guide before taking the certification exam.
