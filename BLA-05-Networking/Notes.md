
### Key takeaways
* VPC = isolated virtual network.
* Subnet = IP range within a VPC and one Availability Zone.
* Route table = destination-to-target routing rules.
* Internet Gateway = enables internet connectivity for appropriately configured resources.
* NAT Gateway = outbound IPv4 connectivity for private resources.
* Route 53 = DNS and DNS routing policies.
* CloudFront = CDN, edge locations, and caching.
