## Topic: Cloud Computing & AWS Fundamentals

### Overview

This is the first biweekly project in my AWS Cloud Practitioner learning journey.

In this biweekly, I focused on the fundamentals of cloud computing and AWS. 
The goal was to understand what cloud computing is, why organizations use cloud services, 
how AWS is structured globally, and how AWS services can be used to build applications.


### Learning Objectives

* Understand the basic concept of cloud computing.
* Compare cloud computing with on-premises infrastructure.
* Understand the differences between IaaS, PaaS, and SaaS.
* Understand what AWS is and the types of services it provides.
* Understand AWS Regions, Availability Zones, and Edge Locations.
* Explain the basic benefits of using AWS.


### Topics Covered

#### 1. Cloud Computing

* What is Cloud Computing?
* On-Premises vs. Cloud
* Benefits of Cloud Computing
* Scalability and Flexibility
* Pay-as-you-go pricing
* IaaS, PaaS, and SaaS

#### 2. Introduction to AWS

* What is Amazon Web Services?
* AWS service categories
* Compute, Storage, Database, Networking, and Security
* Examples of common AWS services:
  * Amazon EC2
  * Amazon S3
  * Amazon RDS
  * Amazon DynamoDB
  * Amazon VPC
  * AWS IAM

#### 3. AWS Global Infrastructure

* AWS Regions
* Availability Zones
* Edge Locations
* High Availability
* Regional vs. Global services

### Key Takeaways
The most important concept I learned from this biweekly is that AWS is not a single service. 
It is a cloud platform that provides many different services that can be combined to build and operate applications.

I also learned that AWS organizes its infrastructure into Regions and Availability Zones to support applications 
with different requirements for performance, availability, and geographic location.
