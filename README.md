##  Overview

This repository documents my learning and teaching journey toward the **AWS Certified Cloud Practitioner** certification.

As part of my biweekly learning activities, I study AWS concepts, create educational content, and share what I learn through YouTube and LinkedIn.

The goal of this repository is not only to prepare for the AWS Cloud Practitioner certification, 
but also to demonstrate my ability to understand technical concepts and explain them in a clear and accessible way.


### Learning Approach

For each biweekly period, I follow this learning cycle:
**Learn → Understand → Teach → Share → Document**

* **Learn:** Study AWS concepts using my primary learning resource.
* **Understand:** Review and organize the concepts into practical notes.
* **Teach:** Create three educational YouTube videos.
* **Share:** Create three LinkedIn posts based on the topics learned.
*  **Document:** Organize notes, content, and resources in this repository.

# Learning Philosophy

> **Don't just memorize AWS services. Understand the problem each service solves.**

For each topic, I focus on understanding:
* What is it?
* Why does it exist?
* What problem does it solve?
* When should it be used?
* How is it different from similar services?
* What are the important concepts for the AWS Cloud Practitioner exam?

This approach helps me move from simply memorizing AWS terminology to understanding how AWS services work together in real-world cloud environments.
